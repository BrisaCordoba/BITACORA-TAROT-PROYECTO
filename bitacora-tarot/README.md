# Bitácora Digital de Tarot — TP Final Generación T - Brisa Cordoba


Aplicación web full-stack desarrollada bajo metodología **Spec-Driven Development**, con arquitectura en capas (`Controller - Service - Repository`), base de datos relacional PostgreSQL y despliegue en la nube.

## Stack Tecnológico
- **Frontend:** React + Vite (Desplegado en Netlify)
- **Backend:** Node.js + Express (Desplegado en Render)
- **Base de Datos:** PostgreSQL (Alojada en Neon)
- **Testing:** Node Test Runner nativo (`node --test`)
